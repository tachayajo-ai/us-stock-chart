# REIT และอสังหาริมทรัพย์

## หาเงินอย่างไร
ค่าเช่าจากอสังหาริมทรัพย์ ต้องจ่ายปันผลอย่างน้อย 90% ของกำไรที่ต้องเสียภาษี → โตด้วยการกู้เงินหรือเพิ่มทุน
แยกประเภท: อุตสาหกรรม/คลังสินค้า (PLD), ศูนย์ข้อมูล (EQIX, DLR), เสาสัญญาณ (AMT, CCI), ที่อยู่อาศัย, ห้างร้าน (O, SPG), สำนักงาน, สุขภาพ (WELL, DOC), ห้องเย็นและห้องแล็บ (ARE), คาสิโน (VICI)

## ตัวชี้วัดสำคัญ
| ตัวชี้วัด | ดีคือ | ทำไม |
|---|---|---|
| **FFO / AFFO ต่อหุ้น** | โตต่อเนื่อง | ใช้แทนกำไรสุทธิ (กำไรสุทธิหักค่าเสื่อมของตึกที่จริงมูลค่าไม่ลด) |
| Occupancy | 95%+ | |
| Same-property NOI growth | บวก, สูงกว่าเงินเฟ้อ | การเติบโตจากทรัพย์สินเดิม |
| Leasing spread | ค่าเช่าใหม่สูงกว่าเดิม | อำนาจต่อรองค่าเช่า |
| WALE (อายุสัญญาเช่าเฉลี่ยที่เหลือ) | ยาว + มีค่าเช่าปรับขึ้นในสัญญา | ความมั่นคงของรายได้ |
| หนี้สุทธิ ÷ EBITDA | < 6 เท่า | |
| AFFO payout | < 85% | ปันผลยั่งยืน |
| คุณภาพผู้เช่าและการกระจุกตัว | ผู้เช่ารายใหญ่ < 10% | |

## MOAT ที่พบบ่อย
ทำเลที่หาแทนไม่ได้, เครือข่าย (เสาสัญญาณ, ศูนย์ข้อมูลที่เชื่อมกันเป็นระบบ), ต้นทุนเงินทุนต่ำ (REIT ใหญ่กู้ได้ถูกกว่า ทำให้ซื้อทรัพย์ได้คุ้มกว่า)

## วิธีอ่าน Buffett checklist ของแอพ
ROE ต่ำ, หนี้สูง, จำนวนหุ้นเพิ่ม และ net margin ต่ำเป็นเรื่องปกติของ REIT (ค่าเสื่อม + ต้องเพิ่มทุนเพื่อโต) — ให้ดู FFO ต่อหุ้นโตหรือไม่แทน

## Red flags
Occupancy ลด, ผู้เช่ารายใหญ่มีปัญหา, หนี้ครบกำหนดก้อนใหญ่ช่วงดอกเบี้ยสูง, เพิ่มทุนตอนราคาหุ้นต่ำกว่า NAV, ประเภทอสังหาที่ความต้องการลดเชิงโครงสร้าง (สำนักงานหลังการทำงานทางไกล)

## ประเมินมูลค่า
P/FFO, P/AFFO เทียบกลุ่มย่อยเดียวกัน, ราคาเทียบ NAV, cap rate เทียบดอกเบี้ย, ผลตอบแทนปันผล + การเติบโตของ AFFO

## คำถามสำหรับ earnings call
Occupancy และ leasing spread, แผนซื้อหรือขายทรัพย์สิน, หนี้ครบกำหนดและต้นทุนการกู้, guidance ของ AFFO
