# ประกันภัย / ประกันชีวิต / รับประกันภัยต่อ

## หาเงินอย่างไร
1. **กำไรจากการรับประกันภัย (underwriting)**: เบี้ยที่รับมากกว่าค่าสินไหม + ค่าใช้จ่าย
2. **ผลตอบแทนจาก float**: เงินเบี้ยที่ถือไว้ก่อนจ่ายสินไหม นำไปลงทุน (โมเดลของ Buffett/Berkshire)

## ตัวชี้วัดสำคัญ
| ตัวชี้วัด | ดีคือ | ทำไม |
|---|---|---|
| Combined ratio (ประกันวินาศภัย) | < 100% ต่อเนื่อง, ดีมาก < 95% | ต่ำกว่า 100% = ได้กำไรจากการรับประกันโดยไม่นับการลงทุน → float มีต้นทุนติดลบ |
| Loss ratio / Expense ratio | เทียบคู่แข่งในสายเดียวกัน | แยกว่าดีเพราะคัดเลือกความเสี่ยงเก่งหรือเพราะต้นทุนต่ำ |
| Reserve development | ค่าสำรองปีก่อนๆ ปรับลด (favorable) | ตั้งสำรองระมัดระวัง ถ้าต้องเพิ่มสำรองย้อนหลังบ่อยแปลว่าเคยประเมินต่ำไป |
| ROE | 12%+ ตลอดวัฏจักร | |
| Book value per share growth | โตต่อเนื่องรวมปันผล | ตัววัดหลักของการสร้างมูลค่า |
| Float growth และต้นทุน float | float โต และต้นทุน ≤ 0 | |
| ประกันชีวิต: ส่วนต่างผลตอบแทนการลงทุนกับที่สัญญากับลูกค้า, ความเสี่ยงจากอายุยืนหรืออัตราตาย | | |

## MOAT ที่พบบ่อย
วินัยการรับประกัน (ยอมให้ยอดขายลดเมื่อราคาตลาดไม่คุ้ม), ข้อมูลและการกำหนดราคาความเสี่ยงเฉพาะทาง, ช่องทางจำหน่าย, ต้นทุนต่ำ (เช่น GEICO), สายเฉพาะทาง (specialty) ที่คู่แข่งน้อย

## Red flags
ยอดเบี้ยโตเร็วมากในช่วงที่ราคาตลาดอ่อนตัว (soft market), ต้องเพิ่มสำรองย้อนหลังซ้ำๆ, ลงทุนในสินทรัพย์เสี่ยงเพื่อชดเชยการขาดทุนจากการรับประกัน, ภัยพิบัติกระจุกพื้นที่เดียว

## ประเมินมูลค่า
**P/B เทียบ ROE** และการเติบโตของ book value ต่อหุ้น · Berkshire: ประเมินแยกส่วน (ธุรกิจปฏิบัติการ + พอร์ตลงทุน + float)

## ใน Buffett checklist ของแอพ
DCF และ FCF ใช้ไม่ได้ (เงินเบี้ยทำให้กระแสเงินสดดูสูงเกินจริง) — ใช้ combined ratio, ROE และ P/B

## คำถามสำหรับ earnings call
แนวโน้มราคาเบี้ย (rate change) ในแต่ละสาย, reserve development, ผลกระทบจากภัยพิบัติ, ผลตอบแทนพอร์ตลงทุนที่ลงทุนใหม่
