# พลังงาน, น้ำมันและก๊าซ, เหมือง, เคมีภัณฑ์, วัสดุ

## หลักคิด
ส่วนใหญ่เป็น **ผู้รับราคา (price taker)** ของสินค้าโภคภัณฑ์ → moat เดียวที่จริงคือ **ต้นทุนต่ำที่สุดในอุตสาหกรรม**
ข้อยกเว้นคือท่อส่ง (midstream) ที่คิดค่าบริการตามปริมาณและมี moat แบบ efficient scale

## แยกกลุ่ม
| กลุ่ม | ตัวอย่าง | ขึ้นกับ |
|---|---|---|
| ต้นน้ำ (สำรวจ/ผลิต) | XOM, CVX, COP, FANG, OXY | ราคาน้ำมัน/ก๊าซ, ต้นทุนผลิต |
| กลางน้ำ (ท่อ/คลัง) | KMI, WMB, OKE, TRGP | ปริมาณผ่านท่อ, สัญญาระยะยาว |
| ปลายน้ำ (กลั่น) | MPC, VLO, PSX | ส่วนต่างราคาน้ำมันดิบกับผลิตภัณฑ์ (crack spread) |
| เหมือง/โลหะ | FCX, NEM, NUE | ราคาโลหะ, คุณภาพแหล่งแร่ |
| เคมีภัณฑ์/วัสดุ | LIN, SHW, APD, DOW | specialty มีอำนาจกำหนดราคา, commodity ไม่มี |

## ตัวชี้วัดสำคัญ
| ตัวชี้วัด | ดีคือ |
|---|---|
| ต้นทุนคุ้มทุน (breakeven) ต่อบาร์เรลหรือต่อตัน | อยู่ในกลุ่มต่ำสุดของอุตสาหกรรม (cost curve ล่าง 25%) |
| อายุปริมาณสำรอง (reserve life) และอัตราทดแทนสำรอง | ≥ 10 ปี, ทดแทน ≥ 100% |
| หนี้สุทธิ ÷ EBITDA | < 1.5 เท่า (ต้องรอดช่วงราคาตกได้) |
| ROCE ตลอดวัฏจักร | > ต้นทุนเงินทุน |
| กลางน้ำ: สัดส่วนรายได้ตามค่าบริการ (fee-based), อายุสัญญา, distribution coverage | fee-based 80%+, coverage > 1.2 |
| วินัยการใช้เงิน: คืนเงินให้ผู้ถือหุ้นแทนการขยายกำลังผลิตตอนราคาสูง | |

## วัฏจักรและการอ่านแอพ
- กำไรและ FCF ในแอพสะท้อนราคาสินค้าช่วงนั้น → DCF ช่วงราคาสูงจะให้ MOS สูงเกินจริง
- ให้ประเมินที่ **ราคาสินค้ากลาง** (เช่น น้ำมัน $65–75) แล้วทดสอบที่ราคาต่ำ

## Red flags
ต้นทุนสูงกว่าคู่แข่ง, หนี้สูงก่อนราคาตก, ซื้อกิจการตอนราคาสูงสุด, ปริมาณสำรองลด, ความเสี่ยงสิ่งแวดล้อมหรือคดีความ, การเปลี่ยนผ่านพลังงาน (ความต้องการระยะยาว)

## ประเมินมูลค่า
EV/EBITDA ที่ราคากลาง, NAV (มูลค่าปริมาณสำรอง), FCF yield ที่ราคากลาง · กลางน้ำ: DCF/EV-EBITDA + ความมั่นคงของปันผล · Specialty chemicals: DCF ปกติ

## คำถามสำหรับ earnings call
ต้นทุนต่อหน่วย, แผน capex และการผลิต, สมมติฐานราคาในงบ, นโยบายคืนเงินผู้ถือหุ้น, ปริมาณสำรอง
