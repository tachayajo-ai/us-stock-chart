# บริการการเงินที่ไม่ใช่ธนาคาร: เครือข่ายชำระเงิน, ตลาดหลักทรัพย์, ข้อมูล/เรตติ้ง, จัดการกองทุน, โบรกเกอร์

## แยกตามโมเดล
| โมเดล | ตัวอย่าง | หาเงินจาก |
|---|---|---|
| เครือข่ายชำระเงิน | V, MA, AXP (ส่วนเครือข่าย) | ค่าธรรมเนียมต่อยอดใช้จ่ายและธุรกรรม **ไม่รับความเสี่ยงสินเชื่อ** (ยกเว้น AXP ที่ปล่อยกู้เอง → ใช้ banks.md ร่วม) |
| ตลาดหลักทรัพย์ / clearing | ICE, CME, NDAQ, CBOE | ค่าธรรมเนียมซื้อขาย + ขายข้อมูลราคา + บริการ listing |
| ข้อมูล / เรตติ้ง / ดัชนี | SPGI, MCO, MSCI, FDS | ค่าสมาชิกรายปี + ค่าจัดอันดับ + ค่าใช้ชื่อดัชนี (ผูกกับขนาดสินทรัพย์ที่อ้างอิง) |
| จัดการกองทุน | BLK, TROW, BX, KKR | ค่าธรรมเนียม % ของสินทรัพย์ (AUM) + ส่วนแบ่งกำไร (performance fee) |
| โบรกเกอร์ / wealth | SCHW, IBKR, RJF | ดอกเบี้ยจากเงินสดของลูกค้า + ค่าธรรมเนียม + ค่าบริหารสินทรัพย์ |

## ตัวชี้วัดสำคัญ
- **เครือข่ายชำระเงิน**: การเติบโตของยอดใช้จ่าย (payments volume), cross-border volume (margin สูงสุด), จำนวนธุรกรรม, operating margin (V/MA 55%+), incentive ที่จ่ายให้ธนาคาร/ลูกค้ารายใหญ่ ÷ รายได้รวม
- **ตลาด / ข้อมูล**: สัดส่วนรายได้ประจำ (recurring), retention rate ของลูกค้า, การขึ้นราคาประจำปี, organic growth, ส่วนแบ่งการซื้อขาย
- **จัดการกองทุน**: การเติบโตของ AUM แยกเป็นเงินไหลเข้าสุทธิ (net flows) กับผลจากตลาด, fee rate (กำลังถูกกดลงจาก passive), ผลงานเทียบดัชนี, สัดส่วน alternatives/private
- **โบรกเกอร์**: บัญชีใหม่, net new assets, รายได้ดอกเบี้ยจากเงินสดลูกค้า (อ่อนไหวต่อดอกเบี้ยและการโยกเงินสด)

## MOAT ที่พบบ่อย
Network effect สองฝั่ง (V/MA: ร้านค้า ↔ ผู้ถือบัตร), ใบอนุญาตและข้อกำหนดตามกฎหมาย (เรตติ้งที่ตลาดบังคับใช้), ข้อมูลและมาตรฐานที่ลูกค้าฝังอยู่ในระบบ (switching cost), สภาพคล่องรวมศูนย์ (ตลาดที่มีผู้ซื้อขายมากที่สุดยิ่งดึงคนเพิ่ม)

## Red flags
กฎหมายจำกัดค่าธรรมเนียม (interchange, คดีผูกขาด), ระบบชำระเงินทางเลือก (real-time payments, stablecoin), เงินไหลออกจากกองทุน active ต่อเนื่อง, รายได้จากดอกเบี้ยลดเมื่อดอกเบี้ยลง

## ประเมินมูลค่า
เครือข่ายชำระเงินและบริษัทข้อมูลใช้ **DCF จาก FCF ได้ตามปกติ** (เงินทุนต่ำ เงินสดสูง) + P/E เทียบอัตราเติบโต · จัดการกองทุน: P/E และ % ของ AUM · โบรกเกอร์: P/E + ความอ่อนไหวต่อดอกเบี้ย

## คำถามสำหรับ earnings call
แนวโน้มยอดใช้จ่ายและ cross-border, ผลของกฎหมายหรือคดีความ, การขึ้นราคา, net flows แยกตามประเภทผลิตภัณฑ์
