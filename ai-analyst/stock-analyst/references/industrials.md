# อุตสาหกรรมการผลิต, การบิน/อวกาศ/กลาโหม, ขนส่ง, ก่อสร้าง

## แยกกลุ่ม
| กลุ่ม | ตัวอย่าง | ลักษณะ |
|---|---|---|
| เครื่องจักร/อุปกรณ์ | CAT, DE, ETN, PH | วัฏจักร, รายได้อะไหล่และบริการ (aftermarket) |
| การบิน/อวกาศ/กลาโหม | GE, RTX, LMT, BA | backlog ยาว, aftermarket margin สูง |
| ขนส่ง (รถไฟ, logistics, สายการบิน) | UNP, UPS, ODFL, UAL | ปริมาณขนส่ง, ประสิทธิภาพการดำเนินงาน |
| บริการธุรกิจ/ที่ปรึกษา | ADP, PAYX, CTAS, LDOS | สัญญาต่อเนื่อง ใช้ทุนน้อย |
| ก่อสร้าง/บ้าน | DHI, PHM | ดอกเบี้ย, ความต้องการที่อยู่อาศัย |

## ตัวชี้วัดสำคัญ
| ตัวชี้วัด | ดีคือ | ทำไม |
|---|---|---|
| Backlog และ book-to-bill | backlog โต, B/B > 1 | ทัศนวิสัยรายได้ข้างหน้า |
| Aftermarket ÷ รายได้ | สูง | margin สูง ไม่ผันผวนตามวัฏจักร |
| Organic growth (ไม่นับการซื้อกิจการ) | บวก | |
| Incremental margin | 25–35%+ | กำไรเพิ่มเท่าไรต่อยอดขายที่เพิ่ม 1 ดอลลาร์ |
| FCF conversion (FCF ÷ กำไรสุทธิ) | ≥ 90–100% | คุณภาพกำไร |
| รถไฟ: operating ratio | < 60% | ประสิทธิภาพ (ต่ำดี) |
| สายการบิน: CASM, RASM, load factor | | ต้นทุนและรายได้ต่อที่นั่งไมล์ |
| ROIC | 15%+ ตลอดวัฏจักร | |

## MOAT ที่พบบ่อย
ฐานเครื่องที่ติดตั้งแล้วสร้างรายได้อะไหล่ระยะยาว (เครื่องยนต์อากาศยาน), ขนาดที่มีประสิทธิภาพ (รถไฟ: เส้นทางที่สร้างซ้ำไม่ได้), ใบรับรองและข้อกำหนดด้านความปลอดภัย, เครือข่ายตัวแทนจำหน่าย (CAT), ต้นทุนต่ำ (ODFL)
สายการบิน: แทบไม่มี moat (Buffett เคยบอกว่าเป็นธุรกิจที่แย่ที่สุด) — ระวัง MOS สูงจาก DCF ช่วงกำไรพีค

## Red flags
backlog ลดหรือลูกค้ายกเลิก, ปัญหาคุณภาพหรือความปลอดภัย (เช่น BA), สัญญาราคาคงที่ที่ต้นทุนบานปลาย, การเติบโตจากการซื้อกิจการพร้อมหนี้สูง, กำไรพีคในวัฏจักร

## ประเมินมูลค่า
P/E และ EV/EBITDA บนกำไรเฉลี่ยทั้งวัฏจักร, DCF สำหรับบริษัทที่มี aftermarket และสัญญาต่อเนื่อง · ก่อสร้างบ้าน: P/B

## คำถามสำหรับ earnings call
ยอดสั่งซื้อและ backlog, ราคาเทียบต้นทุนวัตถุดิบ, ห่วงโซ่อุปทาน, ภาษีนำเข้า, งบกลาโหมหรืองบโครงสร้างพื้นฐานของรัฐ
